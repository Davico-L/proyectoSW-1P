# Estructura del Proyecto

Este repositorio contiene la arquitectura base para el desarrollo del sistema, organizado en los siguientes directorios principales:

## Estructura de Directorios

- **`/frontend`**: Contiene la aplicación web cliente (desarrollada en React). Aloja la interfaz de usuario web, componentes, estilos y la lógica de presentación del frontend.
- **`/backend`**: Contiene el servicio y lógica del servidor (desarrollado en Node.js). Aloja los endpoints de API, servicios de negocio, modelos y conexiones a bases de datos.
- **`/mobile-template`**: Plantilla base para la aplicación móvil (desarrollada en Flutter). Contiene la estructura inicial para el desarrollo móvil multiplataforma.
- **`/docs`**: Documentación técnica general del proyecto, especificaciones de arquitectura y registro de decisiones de diseño (`decisiones.md`).
